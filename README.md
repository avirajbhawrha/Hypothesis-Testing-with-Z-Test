  Hypothesis Testing with Z-Test (Z-Test Statistical Analysis using P-Value)

 Overview

This demonstrates the implementation of a Z-Test using Python to perform statistical hypothesis testing. The analysis focuses on calculating the **p-value** and making decisions based on significance levels.

 Objective
* To understand and apply the Z-Test in hypothesis testing
* To calculate p-values using Python
* To interpret results for decision-making

 Concepts Used
* Hypothesis Testing
* Z-Test
* P-Value
* Null Hypothesis (H₀)
* Alternative Hypothesis (H₁)
* Significance Level (α)

 Technologies Used
* Python 🐍
* NumPy
* SciPy / Statistics libraries
* Jupyter Notebook


 Workflow
1. Define the hypothesis (H₀ and H₁)
2. Set significance level (α)
3. Calculate Z-score
4. Compute p-value
5. Compare p-value with α
6. Draw conclusion


 Output
* Z-score calculation
* P-value result
* Final decision (Reject or Accept H₀)

Example Use Case
This method can be used in:
* Business decision-making
* A/B testing
* Quality control
* Research analysis
